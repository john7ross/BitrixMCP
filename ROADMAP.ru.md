# Дорожная карта и статус

[English](ROADMAP.md) · **Русский**

## Статус: функционально готов (v0.1.0)

Набор инструментов для этого релиза закрыт. 87 типизированных инструментов на 15
доменов плюс универсальный хребет `b24_call` / `b24_batch` (100% охват API),
чтение и запись, оба транспорта. Офлайн-верификация зелёная; живая проверка на
реальном портале — единственный открытый шаг, его выполняет оператор из своей
сети (`scripts/smoke.py`), так как у сборочной песочницы нет маршрута до портала.

## История

- **Пересборка по полевым заметкам.** Заменена багованная внутренняя обёртка.
  Задокументированные проблемы исправлены архитектурно, не заплатками:
  - фильтры уходят JSON-телом (чинит игнор фильтра / выгрузку всего портала);
  - ошибки Битрикса всплывают со своим кодом (больше нет фейкового «0
    результатов»);
  - `ownerId` календаря авторезолвится;
  - канбан Scrum через активный спринт + `tasks.api.scrum.kanban.getStages`;
  - телефония через корректный `voximplant.statistic.get`;
  - stdio / stateless HTTP вместо хрупкого SSE-моста `mcp-remote`.
- **База на чтение → полная запись.** Добавлены CRUD и действия с побочными
  эффектами по CRM, задачам, календарю, диску, мессенджеру, спискам, каталогу,
  группам, бизнес-процессам, с опциональным read-only-гейтом.
- **Ширина для ежедневного использования.** Расширено с 8 до 15
  типизированных доменов (воронки, статусы, активности, реквизиты, товарные
  строки, связи сделка-контакт, стадии/чек-листы/время/результаты задач, рабочие
  группы, заказы, генерация документов, чаты/лента, универсальные списки).

## Вне охвата (осознанно)

- **Типизированное покрытие всего API 1:1.** Сотни методов раздули бы выбор
  инструментов; длинный хвост осознанно закрыт универсальными инструментами.
- **Инфраструктура приложений/событий** (`event.bind`, placements, OAuth-флоу
  приложений) — это webhook-клиент, а не приложение Bitrix Market.
- **Знание о каком-либо потребляющем приложении.** Сервер — generic-шлюз;
  маппинг его вывода в контракт downstream-приложения живёт в агенте, не здесь.
- **Запись корзины/заказов магазина** — многошаговая; пока через `b24_call`,
  до появления явной потребности в типизированном флоу.

## Возможное развитие (не в обязательствах)

- Типизированные обёртки для открытых линий и почты, если появится ежедневный
  спрос.
- Курсорный хелпер для очень больших выгрузок сверх лимита страниц.
- Опциональная авторизация по API-ключу перед HTTP-транспортом.
